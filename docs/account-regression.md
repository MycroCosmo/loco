# 계정 탈퇴 회귀 수정

## 변경 사항

- JWT 검증 시 DB에서 현재 사용자 존재·탈퇴 상태를 확인합니다. 서명과 만료 검증은 기존 Passport 전략이 수행합니다.
- 탈퇴 상태 기록, FCM 토큰 해제, 활성 리프레시 토큰 폐기, 미사용 비밀번호 재설정 토큰 사용 처리를 하나의 Prisma 트랜잭션으로 묶습니다.
- 서비스의 직접 프로필 조회도 탈퇴 사용자를 제외합니다.

## 검증

```bash
cd apps/server
npm ci
npx prisma generate
npm test -- --runInBand
npm run build
```

Jest 테스트 9개를 추가했습니다. 별도의 의존성 격리 실행에서는 동일한 프로덕션 메서드에 대한 9개 검사 중 수정 전 7개가 실패했고 수정 후 9개가 통과했습니다. 이 결과는 실제 PostgreSQL 롤백, Nest 의존성 주입, HTTP 요청 검증을 대체하지 않습니다. GitHub Actions에는 Jest·빌드 작업을 추가했으며 실행 결과를 별도로 확인해야 합니다.

## 범위와 한계

이 변경은 탈퇴 후 새로 인증되는 요청의 차단입니다. 이미 인증을 통과한 실행 중 요청을 취소하지 않습니다. 비밀번호 변경 또는 로그아웃 시 모든 기존 액세스 토큰을 즉시 폐기하는 session-version 기능도 포함하지 않습니다. 탈퇴와 재발급의 실제 동시 실행은 DB 통합 테스트 대상으로 남깁니다.

## 병합 전

기본 브랜치 README의 탈퇴 제한 설명은 아직 배포된 코드 기준입니다. 이 PR 병합·배포 시 실제 검증 결과와 함께 해당 제한 설명을 갱신해야 합니다. 운영 환경이나 저장소 공개 범위는 변경하지 않습니다.
